YouTube動画の再生方法

HTMLを直接ダブルクリックするとサイトを読めますが、ローカルファイルのURLでは通常YouTubeが求める参照元識別情報を提供できず、エラー153が出る場合があります。ページ内で再生するには、以下の方法でローカルサイトを起動するか、公開済みHTTPSサイトを開いてください。動画の視聴にはインターネット接続が必要です。

Mac：ローカルサイトを起動

  1. サイト一式を完全に展開し、 SmartAction フォルダーに入ります。
  2. 同じ階層にあるファイルをダブルクリックします： 啟動網站_Mac.command。Python 3が必要です。Condaをお使いの場合、有効化した環境のターミナルからも実行できます。
  3. ブラウザーが自動でローカルサイトを開きます。通常のURLは http://127.0.0.1:8765/index.htmlです。ポートが使用中の場合は、起動ウィンドウに実際に表示されたURLを使用してください。
  4. ページのYouTube再生ボタンをクリックしてください。起動ウィンドウは開いたままにし、終了後にそのウィンドウで Control+C を押して停止します。

起動できない場合は「ターミナル」を開き、次のように入力します： cd （後ろに空白を一つ入れる）、展開したSmartActionフォルダーをターミナルにドラッグし、Enterを押してから次を入力します：

python3 start_server.py

Python 3が見つからない場合は、Python 3をインストールするか、Python 3がインストール済みのConda環境を使ってください。起動プログラムはPython標準ライブラリのみを使用し、npmや追加パッケージは不要です。

WindowsとLinux

Windows：Python 3をインストール後、ダブルクリックします： 啟動網站_Windows.bat。Linux：サイトのフォルダーで次を実行します： bash 啟動網站_Linux.sh。起動ウィンドウに表示されたURLを開き、ウィンドウは開いたままにしてください。

GitHub Pagesへ公開

サイトの全内容をGitHub Pagesへアップロードしたら、実際に公開されたHTTPS URLを開くと、サイト内のYouTubeプレーヤーを使用できます。一般の訪問者はローカルプログラムを起動する必要がありません。設定手順はパッケージの「配置與操作說明.txt」を参照してください。ローカル起動プログラムはサイトを公開しません。

再生できない場合

まずURLが次で始まるか確認してください： http:// または https:// 。次ではありません： file://。インターネット接続も確認してください。動画が削除された、非公開にされた、または埋め込みが禁止された場合は、YouTubeと投稿者の設定に従います。プレーヤー下の「YouTubeで見る」リンクも利用できます。
