# 聰動無人機模擬操控

這是一個完全在瀏覽器內執行的輕量無人機練習遊戲。核心模擬、場景與介面均由原生 HTML、CSS、JavaScript 及 Canvas 2D 製作，沒有 CDN、第三方套件或外部模型。

## 開啟方式

建議從 SmartAction 根目錄啟動既有的本機伺服器，再瀏覽：

```text
http://localhost:8000/動動腦/無人機模擬操控/
```

直接雙擊 `index.html` 也能執行核心模擬；透過 HTTP 開啟時，共用語言選單與支持面板的載入最可靠。

## 操作

鍵盤採 Mode 2 配置：

- `W` / `S`：增加／降低油門；初學者模式改為調整目標高度。
- `A` / `D`：向左／向右偏航。
- `↑` / `↓`：向前／向後俯仰。
- `←` / `→`：向左／向右滾轉。
- `Space`：暫停／繼續。
- `V`：第一人稱／第三人稱鏡頭。
- `R`：重設賽道與分數。
- `F`：切換全螢幕。

觸控裝置顯示兩個真正的虛擬搖桿：左側為油門／偏航，右側為俯仰／滾轉；沒有顯示或模擬手機鍵盤。

## 實作重點

- 120 Hz 固定時間步長物理，畫面更新與物理解耦。
- 初學者自動懸停、一般輕度穩定、專家手動姿態三種模式。
- Canvas 透視投影的虛構 3D 場景、8 個圓環、計分與計時加分。
- 第一人稱與第三人稱鏡頭、FPS 與飛行遙測。
- 依 FPS 自動降低／恢復裝置像素比上限，避免高解析螢幕過度耗能。
- 共用 `../../assets/portal-i18n.js`、`portal.css`、`engage.js`；缺少共用資產時仍保留繁體中文核心介面與完整遊戲功能。
- 頁面離開可見狀態時自動暫停；資料只存在目前分頁記憶體，不上傳。

## 已知限制

- 這是以易懂與低負載為目標的簡化模型，不模擬馬達、電池、風場、GPS、感測器偏差、碰撞體或特定實機的飛控韌體。
- 場景是程式生成的虛構地景，不使用地圖圖磚，也不是實際導航、禁限航區或飛行許可資料。
- 圓環均以固定方向排列；沒有任務編輯器、網路排名或永久存檔。
- 專家模式提供較少的自穩定，但仍有速度限制與世界邊界，以維持瀏覽器練習的可用性。
- 這不是飛行認證、專業訓練、醫療或復健治療。實際飛行應查閱臺灣民航局或所在司法管轄區的最新規範。

本專案沒有移植、反編譯或使用 PhoenixRC、Unity 執行檔或其他專有模擬器的程式碼、二進位內容、模型、材質或音訊。

## 檢查

在本目錄執行：

```bash
node --check simulator.js
node tests/smoke.mjs
node tests/runtime-smoke.mjs
```

第二個指令會檢查必要檔案、相對資產路徑、安全說明、Mode 2 配置、固定時間步長、觸控搖桿、語言 fallback，以及無 CDN／Strikingly 相依性。第三個指令在模擬 DOM 與 Canvas 環境中實際啟動程式，驗證固定步長迴圈、鍵盤輸入、前進／升高、暫停與重設。此環境未附可用 Chromium，因此仍應在目標手機與桌面瀏覽器做最後視覺與觸控確認。
