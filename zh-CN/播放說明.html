YouTube 影片播放方式

直接双击 HTML 可阅读网站，但本机档案网址通常无法提供 YouTube 要求的来源识别，可能出现错误 153。要在网页内播放影片，请使用下列本机网站方式，或开启已发布的 HTTPS 网站。观看影片都需要网路。

Mac：启动本机网站

  1. 完整解压缩网站套件，进入 SmartAction 资料夹。
  2. 双击同层的 启动网站_Mac.command。需要已安装 Python 3；已有 Conda 的使用者也可从已启用环境的终端机执行。
  3. 浏览器会自动开启本机网站，网址通常为 http://127.0.0.1:8765/index.html。如果埠号已使用，请以上方启动视窗实际显示的网址为准。
  4. 在网页中点选 YouTube 播放按钮。保持启动视窗开启；观看结束后，在该视窗按 Control+C 停止。

若启动器无法开启，请开启「终端机」，输入 cd （后面有一个空格），将解压缩后的 SmartAction 资料夹拖进终端机，按 Enter，再输入：

python3 start_server.py

若显示找不到 Python 3，需先安装 Python 3，或使用已安装 Python 3 的 Conda 环境。启动器只使用 Python 标准函式库，不需 npm 或额外套件。

Windows 与 Linux

Windows：安装 Python 3 后，双击 启动网站_Windows.bat。Linux：在网站资料夹执行 bash 启动网站_Linux.sh。依启动视窗显示的网址开启，并保持视窗开启。

发布至 GitHub Pages

将完整网站内容上传 GitHub Pages 后，开启实际发布的 HTTPS 网址，即可使用网站内的 YouTube 播放器。一般访客无须启动本机程式。配置步骤见套件内「配置与操作说明.txt」。本机启动器不会替您发布网站。

仍无法播放时

先确认网址以 http:// 或 https:// 开头，而非 file://，并确认已连上网路。影片被移除、设定私人或禁止嵌入时，仍受 YouTube 与影片作者的设定限制；可使用播放器下方的「在 YouTube 观看」连结。

官方说明：YouTube 播放器错误码。
