Comment lire les vidéos YouTube

Un double-clic sur le fichier HTML permet de lire le site, mais une adresse de fichier local ne fournit généralement pas l’identification de la source exigée par YouTube, ce qui peut provoquer l’erreur 153. Pour lire les vidéos dans la page, utilisez la méthode de site local ci-dessous ou ouvrez le site HTTPS publié. Une connexion Internet est nécessaire pour regarder les vidéos.

Mac : démarrer le site local

  1. Décompressez entièrement le paquet du site, puis ouvrez le SmartAction dossier.
  2. Double-cliquez sur le fichier situé dans le même dossier : 啟動網站_Mac.command. Python 3 doit être installé. Les utilisateurs de Conda peuvent aussi le lancer depuis un terminal où leur environnement est activé.
  3. Le navigateur ouvrira automatiquement le site local, généralement à l’adresse http://127.0.0.1:8765/index.html. Si le port est déjà utilisé, prenez l’adresse effectivement affichée dans la fenêtre de lancement ci-dessus.
  4. Cliquez sur le bouton de lecture YouTube dans la page. Laissez la fenêtre de lancement ouverte ; après le visionnage, appuyez sur Control+C pour arrêter.

Si le lanceur ne s’ouvre pas, ouvrez le Terminal et saisissez cd (avec un espace après), faites glisser le dossier SmartAction décompressé dans le Terminal, appuyez sur Entrée, puis saisissez :

python3 start_server.py

Si Python 3 est introuvable, installez-le d’abord ou utilisez un environnement Conda qui le contient déjà. Le lanceur utilise uniquement la bibliothèque standard de Python et ne nécessite ni npm ni paquet supplémentaire.

Windows et Linux

Windows : après avoir installé Python 3, double-cliquez sur 啟動網站_Windows.bat. Linux : dans le dossier du site, exécutez bash 啟動網站_Linux.sh. Ouvrez l’adresse affichée dans la fenêtre de lancement et laissez cette fenêtre ouverte.

Publier sur GitHub Pages

Après avoir téléversé l’intégralité du site sur GitHub Pages, ouvrez son adresse HTTPS publiée pour utiliser les lecteurs YouTube intégrés. Les visiteurs ordinaires n’ont pas à lancer de programme local. Consultez le fichier « 配置與操作說明.txt » du paquet pour les étapes de configuration. Le lanceur local ne publie pas le site à votre place.

Si la lecture échoue toujours

Vérifiez d’abord que l’URL commence par http:// ou https:// , plutôt que par file://, et vérifiez votre connexion Internet. Si une vidéo a été supprimée, rendue privée ou interdite à l’intégration, les paramètres de YouTube et de son auteur restent applicables ; utilisez le lien « Regarder sur YouTube » sous le lecteur.

Instructions officielles : Codes d’erreur du lecteur YouTube。
