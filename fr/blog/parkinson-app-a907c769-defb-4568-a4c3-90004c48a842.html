【Communication médecin–patient】La connexion Web sur ordinateur a été mise à jour. Il n’est plus nécessaire de saisir le numéro de téléphone mobile ; le code de vérification pour consultation par le médecin suffit !!!

Saisir directement l’URL (facile à retenir) : PDnoteAPP.com
