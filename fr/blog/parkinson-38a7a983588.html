Solution au problème récent de connexion à la version web avec le « code d’accès pour le médecin »

Le résumé sauvegardé de l’article figure ci-dessous ; le texte intégral reste à ajouter.

Si la connexion Web échoue après saisie du « Code de vérification pour consultation par le médecin »,

vérifiez d’abord que la version affichée au bas de la page est v1.07.

Certains navigateurs chargent l’ancienne version v1.06 depuis leur cache, ce qui empêche la connexion ;

ouvrez les paramètres du navigateur et cherchez « Confidentialité et sécurité », « Supprimer les données de navigation », « Vider le cache » ou des options similaires.

Actualisez ensuite la page ; une fois v1.07 affiché, cela devrait fonctionner.
