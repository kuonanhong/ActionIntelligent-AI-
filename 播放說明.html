YouTube 影片播放方式

直接雙擊 HTML 可閱讀網站，但本機檔案網址通常無法提供 YouTube 要求的來源識別，可能出現錯誤 153。要在網頁內播放影片，請使用下列本機網站方式，或開啟已發布的 HTTPS 網站。觀看影片都需要網路。

Mac：啟動本機網站

  1. 完整解壓縮網站套件，進入 SmartAction 資料夾。
  2. 雙擊同層的 啟動網站_Mac.command。需要已安裝 Python 3；已有 Conda 的使用者也可從已啟用環境的終端機執行。
  3. 瀏覽器會自動開啟本機網站，網址通常為 http://127.0.0.1:8765/index.html。如果埠號已使用，請以上方啟動視窗實際顯示的網址為準。
  4. 在網頁中點選 YouTube 播放按鈕。保持啟動視窗開啟；觀看結束後，在該視窗按 Control+C 停止。

若啟動器無法開啟，請開啟「終端機」，輸入 cd （後面有一個空格），將解壓縮後的 SmartAction 資料夾拖進終端機，按 Enter，再輸入：

python3 start_server.py

若顯示找不到 Python 3，需先安裝 Python 3，或使用已安裝 Python 3 的 Conda 環境。啟動器只使用 Python 標準函式庫，不需 npm 或額外套件。

Windows 與 Linux

Windows：安裝 Python 3 後，雙擊 啟動網站_Windows.bat。Linux：在網站資料夾執行 bash 啟動網站_Linux.sh。依啟動視窗顯示的網址開啟，並保持視窗開啟。

發布至 GitHub Pages

將完整網站內容上傳 GitHub Pages 後，開啟實際發布的 HTTPS 網址，即可使用網站內的 YouTube 播放器。一般訪客無須啟動本機程式。配置步驟見套件內「配置與操作說明.txt」。本機啟動器不會替您發布網站。

仍無法播放時

先確認網址以 http:// 或 https:// 開頭，而非 file://，並確認已連上網路。影片被移除、設定私人或禁止嵌入時，仍受 YouTube 與影片作者的設定限制；可使用播放器下方的「在 YouTube 觀看」連結。
