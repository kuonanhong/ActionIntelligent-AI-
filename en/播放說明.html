How to play YouTube videos

Double-clicking the HTML file lets you read the website, but a local file URL usually cannot provide the source identification required by YouTube, so error 153 may appear. To play videos within the page, use the local website method below or open the published HTTPS website. Watching videos requires an internet connection.

Mac: Start the local website

  1. Fully extract the website package, then open the SmartAction folder.
  2. Double-click the file in the same folder: 啟動網站_Mac.command. Python 3 must be installed. Conda users can also run it from a terminal with their environment activated.
  3. The browser will automatically open the local website, usually at http://127.0.0.1:8765/index.html. If the port is already in use, use the actual URL shown in the launch window above.
  4. Click the YouTube play button on the page. Keep the launch window open; when you are finished watching, press Control+C to stop.

If the launcher does not open, open Terminal and type cd (with a space after it), drag the extracted SmartAction folder into Terminal, press Enter, then type:

python3 start_server.py

If Python 3 cannot be found, install Python 3 first or use a Conda environment that already has Python 3. The launcher uses only the Python standard library and requires neither npm nor additional packages.

Windows and Linux

Windows: After installing Python 3, double-click 啟動網站_Windows.bat. Linux: In the website folder, run bash 啟動網站_Linux.sh. Open the URL shown in the launch window and keep that window open.

Publish to GitHub Pages

After uploading the complete website to GitHub Pages, open its actual published HTTPS URL to use the YouTube players within the website. Ordinary visitors do not need to start a local program. See “配置與操作說明.txt” in the package for setup steps. The local launcher does not publish the website for you.

If playback still fails

First check that the URL starts with http:// or https:// , rather than file://, and check your Internet connection. If a video has been removed, made private, or disabled for embedding, it remains subject to the settings of YouTube and its creator; use the “Watch on YouTube” link below the player.

Official instructions: YouTube player error codes。
