Cómo reproducir vídeos de YouTube

Puede leer el sitio haciendo doble clic en el HTML, pero las direcciones de archivos locales normalmente no proporcionan la identificación de origen que exige YouTube y puede aparecer el error 153. Para reproducir vídeos dentro de la página, utilice el método de sitio local explicado a continuación o abra el sitio HTTPS publicado. Para ver los vídeos necesita conexión a Internet.

Mac: iniciar el sitio local

  1. Descomprima por completo el paquete del sitio y entre en la SmartAction carpeta.
  2. Haga doble clic en el archivo de la misma carpeta 啟動網站_Mac.command. Es necesario tener instalado Python 3; si ya utiliza Conda, también puede ejecutarlo desde un terminal con el entorno activado.
  3. El navegador abrirá automáticamente el sitio local; la dirección normalmente será http://127.0.0.1:8765/index.html. Si el puerto ya está ocupado, use la dirección que aparezca realmente en la ventana de inicio.
  4. Pulse el botón de reproducción de YouTube en la página. Mantenga abierta la ventana de inicio; al terminar, pulse en esa ventana Control+C para detener el sitio.

Si no puede abrir el lanzador, abra el Terminal y escriba cd (seguido de un espacio), arrastre la carpeta SmartAction descomprimida al terminal, pulse Enter y luego escriba:

python3 start_server.py

Si aparece un mensaje indicando que no se encuentra Python 3, instale primero Python 3 o use un entorno Conda que ya tenga Python 3. El lanzador solo utiliza la biblioteca estándar de Python; no necesita npm ni paquetes adicionales.

Windows y Linux

Windows: después de instalar Python 3, haga doble clic en 啟動網站_Windows.bat. Linux: ejecute lo siguiente en la carpeta del sitio bash 啟動網站_Linux.sh. Abra la dirección que aparezca en la ventana de inicio y mantenga esa ventana abierta.

Publicar en GitHub Pages

Después de subir el contenido completo del sitio a GitHub Pages, abra su dirección HTTPS publicada para utilizar el reproductor de YouTube del sitio. Los visitantes habituales no necesitan iniciar un programa local. Consulte los pasos de configuración en «配置與操作說明.txt», incluido en el paquete. El lanzador local no publica el sitio por usted.

Si el vídeo sigue sin reproducirse

Primero, comprueba que la dirección empiece por http:// o https:// y no por file://, y comprueba que tienes conexión a Internet. Si el vídeo se ha eliminado, se ha configurado como privado o no permite su inserción, seguirá sujeto a las restricciones de YouTube y de su autor; puedes utilizar el enlace «Ver en YouTube» situado debajo del reproductor.
