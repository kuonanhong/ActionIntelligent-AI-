- Chromium 整合檢查 `tests/portal-browser.cjs`：**52 / 52 通過**。伺服器使用 `/SmartAction/` 子目錄，實測 22 語系首頁切換、阿拉伯語 RTL、390px 手機版、文章由 6 → 14 → 48 列且保留縮圖、68 個資源篩選與空結果、8 個知識章節、兩種語言的 100 題閱讀版。
- 題庫實測來源連結起初隱藏、按提示才顯示、作答後可揭答、答對紀錄重新整理後保留，以及全形英文／大小寫／空白正規化與中文手機填空。
- 工具實測下載有效 PNG、TXT、HTML 投影片及實際編碼的短影片；投影片輸出不包含私人講者備註。投資區實測 CSV 計算與可見圖表、心願清單下載；助理實測本地來源查找且不自動載入模型。模型推論另見助理模組的獨立測試。
- 所有影片均由使用者點擊才建立播放器；直接以 `file://` 開啟時提供 YouTube 外連與本機伺服器提示。由於環境不允許完整 YouTube 播放，本次只驗證播放器建立、來源網址與備援操作，不宣稱已觀看完整影片。
- 本次整合測試無 JavaScript 未處理錯誤、無本地請求 404。已人工檢視桌機及手機首頁、題庫截圖。這是 Linux Chromium 與手機尺寸模擬，不能等同實機 Safari／iOS／Android 逐一測試，也沒有執行十萬人負載測試。
