一、上傳靜態頁面

保留 market/ 的 index.html、styles.css、config.js、data.js、analysis.js、app.js、assets/、README.html。上傳到 SmartAction/market/ 後，網址為 https://kuonanhong.github.io/SmartAction/market/。附件中的測試可保留供維護。

雙擊 index.html 能用科學解說、意願清單和 CSV 分析；網路行情及外部平台仍需連線。瀏覽器封鎖 file:// 的儲存時，可從網站或 localhost 開啟。

二、商品資料與正式銷售

編輯 config.js。shopUrl 已連到原網站使用的協會綠界平台。各商品的 price 預設 null，checkoutUrl 預設空字串；正式開賣時，先在合法銷售平台完成產品、價格、運費、退換貨、隱私與付款流程，再替換對應內容及 checkoutUrl。勿把展示圖當成真實商品照片。

window.SMARTACTION_MARKET_CONFIG = {
  apiBase: "https://your-market-worker.workers.dev",
  shopUrl: "https://smartaction.cashier.ecpay.com.tw/",
  products: [ /* 保留原欄位，更新正式公告資料 */ ]
};

GitHub Pages 使用限制不允許將服務主要用作電子商務或促成商業交易；附加條款提到可接受部分捐款與群募連結。因此主站仍以公益知識與協會資訊為核心；正式商店放在外部平台。如整站未來以銷售為主要目的，應改用允許商業用途的主機。

三、為什麼全球即時行情無法完全靠 GitHub Pages？

GitHub Pages 只提供靜態檔案，不能保管供應商密鑰或執行伺服器。全球報價受各交易所與供應商涵蓋範圍、授權、時差、休市與配額限制；同一個 API 不代表免費涵蓋全球即時資訊。

本次實際請求 TWSE STOCK_DAY_ALL 回傳 HTTP 200 與日期欄位，但未回傳 Access-Control-Allow-Origin。這表示靜態網站的直接 fetch 可能被瀏覽器擋住。因此提供兩個真實途徑：下載官方 JSON 匯入，或部署附件 Worker，由伺服器取得資料再提供受限 CORS 回應。

TWSE STOCK_DAY_ALL 是每日成交資訊，頁面一律標成「每日收盤；非盤中即時」。Alpha Vantage GLOBAL_QUOTE 預設也是日終更新；美股即時或延遲資料需要適當 entitlement。Finnhub 的時效依帳號與市場而異，本版保守標成「延遲程度未經驗證」。查詢結果明列資料日期、抓取時間、來源、資料時效與服務快取。

四、部署可選行情 Worker

先準備 Node.js 與 Cloudflare 帳號。此步驟會把你操作的服務部署到 Cloudflare；費用、額度與市場資料再散布授權需要自行確認。預設 TWSE 不需要金融供應商 API key；Alpha Vantage 與 Finnhub 需要各自帳號。

cd backend/market-worker
npm install
npx wrangler login
# 本機開發，依命令輸出的網址填入網頁服務設定
npx wrangler dev
# 檢查設定與帳號後，再自行部署
npx wrangler deploy

對外部署前，編輯 wrangler.toml 的 ALLOWED_ORIGINS、ALLOWED_SYMBOLS、SYMBOL_CURRENCIES。預設只准許少量明確代碼，防止任意訪客耗盡全站供應商額度。跨市場代碼格式需查供應商文件；如交易所、券種或價格單位不同，也要明確標示幣別與單位。

# 選用 Alpha Vantage 時，透過 secret 提示輸入密鑰
npx wrangler secret put ALPHA_VANTAGE_API_KEY
# 選用 Finnhub 時
npx wrangler secret put FINNHUB_API_KEY

不要把密鑰寫入 config.js、wrangler.toml、Git 提交、前端網址或日誌。密鑰僅由 Worker secret bindings 讀取。

# 取得服務網址後檢查（自行替換 YOUR-WORKER）
curl 'https://YOUR-WORKER.workers.dev/health'
curl 'https://YOUR-WORKER.workers.dev/quote?provider=twse&symbol=2330'
curl 'https://YOUR-WORKER.workers.dev/quote?provider=alpha&symbol=IBM'
curl 'https://YOUR-WORKER.workers.dev/history?provider=alpha&symbol=IBM'

確認回應後，將服務網址寫入 market/config.js 的 apiBase。只填基底網址，不填 /quote。網頁「資料連線設定」也能暫時輸入網址，僅當次使用。

預設 ALPHA_ENTITLEMENT="none"。只有在帳號確實取得所需授權時，才可設定 "realtime" 或 "delayed"；這不會自行購買權限。Alpha Vantage GLOBAL_QUOTE 即使啟用即時權限，本端點目前只明示交易日期，因此頁面註明日期精度限制。需要更精細的逐筆時間，請另接具完整時間戳與授權的資料服務。

五、快取、額度與十萬人流量

Worker 先使用邊緣快取，未命中時進入同一 Durable Object。該物件將同時請求排隊，重用 TWSE 全市場的一份小時快取，並以持久儲存計算每個供應商的日／分鐘請求预算。大型 TWSE JSON 分塊儲存，避免單筆儲存大小限制。回應標示的 cacheSeconds 為保守快取上限；使用者仍應以實際 asOf 為準。

  • TWSE 原始資料快取 1 小時；每日歷史資料與 Alpha 預設日終行情 6 小時。
  • 有權限的即時／延遲行情及 Finnhub 在橋接層快取 60 秒；邊緣另快取 30 秒。這不是逐筆串流報價。
  • 每 IP 的 Worker rate limit 預設每分鐘 30 次（每個 Cloudflare 節點的近似限制，共用網路的使用者也共用額度）；供應商全域預算由 Durable Object 控制。
  • ALPHA_DAILY_LIMIT=25 等設定是本程式保守預算，並不是對供應商目前免費方案的承諾。請依契約調整。
  • 不自動輪詢；使用者按查詢才請求，可減少無意義負載。

這個架構仍未部署或做十萬人壓力測試；Cloudflare、GitHub、供應商都有額度與費用，單一協調物件也有吞吐限制。大型公開服務應先測試容量、集中排程更新熱門代碼、建立監控與降級、依授權設計快取，必要時將熱資料發布到可承受負载的儲存/CDN。任何前端或快取都不能保證免費、無限制的全球即時報價。

六、CSV 與科學分析

date,close
2026-01-02,123.45
2026-01-05,124.00

# 或用調整後收盤價欄位：
date,adjusted_close

上面只是欄位格式示例，不是任何實際股票行情，請使用自己的真實資料。最多 10,000 筆、2 MB；日期需唯一且使用 YYYY-MM-DD，價格需正數，程式自動按日期排序。有 adjusted_close 時優先使用。

所有計算均在瀏覽器。20／60 筆不足時，對應均線顯示 —。年化波動率以日對數報酬的樣本標準差乘以 √交易日假設；資料不連續、跨不同頻率或公司行動未調整時，指標可能失真。最大回撤是樣本期間相對既有最高價格的最大跌幅；不代表未來最坏情況。
