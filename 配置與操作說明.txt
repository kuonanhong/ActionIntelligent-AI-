2. 在自己電腦打開完整功能網站

直接雙擊 HTML 可以閱讀靜態內容、搜尋文章與切換語言，但 YouTube 不宜從 file:// 頁面嵌入播放。
完整播放方式是使用本機 HTTP 網站或 GitHub Pages 的 HTTPS 網址。
本機啟動器只需要 Python 3；沒有 Python 時請安裝 python.org 提供的官方 Python 3。

Windows：雙擊「啟動網站_Windows.bat」。若使用官方 Python 安裝器，勾選 Add Python to PATH。
Mac：在終端機切換到 SmartAction 資料夾，執行 python3 start_server.py。
亦可執行 chmod +x 啟動網站_Mac.command，再開啟此檔。
Linux：切換到 SmartAction 資料夾後，執行 python3 start_server.py，或 sh 啟動網站_Linux.sh。

啟動後瀏覽器打開 http://127.0.0.1:8765/ 。若 8765 被占用，依終端機提示使用其他埠，或執行 python3 start_server.py --port 8800。
需要關閉本機網站時，在終端機按 Control+C。
伺服器只監聽本機，不是對外發布網站。
影片仍需要網路。影片擁有者停用嵌入、設為私人、移除影片、地區限制或使用者網路無法連線 YouTube 時，HTML 無法解除限制。
各影片保留「在 YouTube 觀看」與播放說明入口；程式保留正確 origin 與 Referrer 設定，避免 file:// 常見的播放器來源問題。
本次檢查確認影片嵌入網址與來源設定，沒有保證每個外部影片的串流與權限永久可用。

6. 自動語言與手動選擇

支援繁體中文、簡體中文、英語、法語、日語、西班牙語。
根目錄頁面依「明確 ?lang= 指定 → 已儲存的手動偏好 → 瀏覽器偏好語言」選擇。
zh-CN、zh-Hans、zh-SG 對應簡體；zh-TW、zh-Hant、zh-HK 等對應繁體；en/fr/ja/es 的地區變體對應各語。
不支持的語言若偏好清單還有支持語言，使用第一個支持語言；完全沒有時顯示英文。
這依據 navigator.languages，不是 IP 定位，也不會要求精確位置權限。
因此使用英文瀏覽器的中國讀者可能看到英文，使用繁中瀏覽器的美國讀者可能看到繁中。
這樣尊重讀者的語言偏好，並避免免費 IP 定位服務的隱私、限額、錯誤國別與跨境可用性問題。

頁首選單可以直接切換語言，會切到同一頁的對應語言版本，並記住選擇。
「自動選擇（依瀏覽器）」清除手動指定效果，重新按瀏覽器偏好選擇。
直接打開 en/、fr/、ja/、es/、zh-CN/ 的固定網址會保持該版本，不因 IP 或瀏覽器而強制跳走。
例如 /en/blog/index.html 的文章連結保持英文，語言選單切換仍可回到對應的日文或繁中頁。
繁中根目錄另可用 ?lang=zh-TW、?lang=en、?lang=fr、?lang=ja、?lang=es、?lang=zh-CN 暫時檢視自動入口的指定語言。
固定語言目錄以該目錄的語言為準；測試網址不要用「不同語言目錄＋不同 ?lang」混搭。

本次翻譯涵蓋既有 614 個文字單位，包括首頁、巴金森手記、文章標題与已保存正文、播放說明及下載頁；另翻譯新目錄、操作標籤與動態搜尋計數。

8. 日後修改文字與新增資源

一般使用與發布不需要執行維護工具。
若只修改某個現有語言，可編輯對應 HTML，但這不會自動同步其他語言。
要從繁中來源重建全部語言，可使用「維護工具/重建網站.py」；先安裝 Python 套件：
python3 -m pip install beautifulsoup4 opencc-python-reimplemented
再執行：
python3 維護工具/重建網站.py

此工具使用套件內保存的資源與翻譯資料，沒有呼叫翻譯服務。
主資料在 維護工具/來源資料/：resources-taiwan.json、resources-international.json、i18n/source-units.json、i18n/en.json、fr.json、ja.json、es.json、extra-terms.json。
新增資源需在各語 title/description 同時填好；简中由繁中轉換。修改首頁／文章的新文字也需新增 source-units 記錄並補四個翻譯字典，否則新詞會保留原文字。
維護工具/resources.json、translations.json 是重建時產生的查閱快照，直接改這兩份快照不會改變上面的來源資料。
新文章須在 blog/ 增加繁中 HTML，並手動加入文章索引；重建工具不會憑空取得外部網站全文。
如果換GitHub帳號、儲存庫名稱或正式網域，修改重建工具的 BASE 後重新生成所有頁面與 sitemap；不能只改首頁的 canonical。
套件含48筆既有文章；若日後增加文章，驗證數量應依新內容調整，不需永久限制為48。
